# 📚 StudyBuddy AI

A friendly AI-powered Python learning companion built for a friend
who is learning Python and sometimes struggles to understand
programming concepts.

## 🎯 What It Does

StudyBuddy AI allows a learner to enter a Python concept and receive
a beginner-friendly explanation with an example.

### Features

- 🤖 AI-powered explanations
- 🐍 Focused on Python concepts
- 📖 Beginner-friendly responses
- 💻 Python examples
- 🌐 Runs directly in the browser

## 🧠 Open-Source AI

StudyBuddy AI uses an open-weight AI model through
Hugging Face Transformers.js.

The model runs directly in the browser, making the AI component
a core part of the application rather than simply calling a
closed AI API.

## ❤️ Why I Built It

I built StudyBuddy AI for a friend who is learning Python.

Programming concepts can sometimes be difficult to understand
from traditional documentation alone, so I wanted to create
a simple tool that could explain concepts in a more approachable
way.
